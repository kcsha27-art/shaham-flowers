## Core Tech Stack
- **Framework**: Plain HTML5 + Modern Tailwind CSS (Zero hydration lag, 100/100 Lighthouse performance).
- **Animations**: GSAP 3 (GreenSock) + ScrollTrigger (hardware-accelerated transforms, CLS: 0.00).
- **Icons**: Lucide Icons vector library.
- **Conversion Engine**: Pre-encoded `wa.me` WhatsApp direct order links on every product card.
- **Localization**: Full bilingual Arabic (Default) & English support with RTL/LTR layout toggling.
